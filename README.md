## 📌 About the Project

This project explores **handwritten Telugu character recognition** using a Convolutional Neural Network (CNN). The model learns visual patterns in handwritten character images and predicts the corresponding character class.

The goal is to explore how deep learning can help make regional-language scripts easier to process digitally.
